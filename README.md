**Vision AI**, Google'ın en yeni **Gemini 2.0 Flash** modelini kullanarak görselleri analiz eden, çeviren ve kodlarını çözümleyen modern bir Flutter uygulamasıdır.

Proje, ölçeklenebilirlik ve test edilebilirlik için **Clean Architecture** prensiplerine sadık kalınarak ve **Riverpod** ile State Management yapılarak geliştirilmiştir.

## ✨ Özellikler

* **🧠 Yapay Zeka Gücü:** Google Gemini 2.0 Flash modeli ile ışık hızında görsel analizi.
* **🔐 Güvenli Giriş:** Firebase Authentication ile Email/Şifre tabanlı güvenli oturum yönetimi.
* **🏗️ Sağlam Mimari:** Riverpod ve Clean Architecture (Service-Repository-Controller katmanları).
* **🛡️ Güvenlik:** API anahtarları ve hassas veriler `.gitignore` ile repo dışında tutulur.
* **🎨 Modern UI:** Material 3 tasarım dili ve kullanıcı dostu arayüz.
* **📝 Markdown Desteği:** Yapay zekadan gelen zengin metinleri (kod blokları, kalın yazılar) düzgün görüntüleme.

---

## 🛠️ Kullanılan Teknolojiler

* **[Flutter](https://flutter.dev/):** UI Framework
* **[Riverpod](https://riverpod.dev/):** State Management (Durum Yönetimi)
* **[Firebase Auth](https://firebase.google.com/docs/auth):** Kullanıcı Kimlik Doğrulama
* **[Google Generative AI](https://pub.dev/packages/google_generative_ai):** Gemini API Entegrasyonu
* **[Image Picker](https://pub.dev/packages/image_picker):** Galeri erişimi
* **[Flutter Markdown](https://pub.dev/packages/flutter_markdown):** AI çıktılarını render etmek için
